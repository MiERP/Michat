# 3-law test with Gemma 4 E2B: 10 questions + 1 out-of-scope (2026-11-26)

## Setup

- MiChat 2.2.2, installed Windows build.
- Notebook: `3 luật: SHTT, An ninh mạng, Dữ liệu`.
- Documents and index: 1,160 chunks / 128 sections, BGE-M3 embeddings (1024 dimensions).
- Chat model: `gemma-4-E2B-it-Q4_K_M.gguf`, alias `qwen3.5-4b`, Vulkan backend,
  18 GPU layers, 16,384 context, 4 threads.
- Embeddings: BGE-M3 on `127.0.0.1:8081`.
- Chat endpoint: `http://127.0.0.1:8080/v1`; MiChat discovers the model from
  `/v1/models` and ignores legacy model fields.
- All questions were entered through the chat UI in one session.
- The 11th question names a law that is **not** in the notebook, to verify that
  MiChat refuses instead of answering from general knowledge.

## Language fix

Gemma 4 E2B was emitting its internal reasoning as normal content, sometimes in
Korean, because the llama.cpp chat template's thinking channel was active.
MiChat now sends:

```json
"chat_template_kwargs": { "enable_thinking": false }
```

on chat requests only. With this switch, all 11 answers were in Vietnamese and
no Korean text appeared. The server's actual template must honour the switch;
llama.cpp does.

## Summary

- Fully correct: **6/10**.
- Partial: **2/10** (Q5, Q10).
- Wrong: **2/10** (Q3, Q6).
- Off-topic question: **correctly refused**; no fabricated effective date.
- Language: **11/11 Vietnamese**; no Korean output after disabling template thinking.
- Average TTFT (10 legal questions): **8.9s**; average total: **20.6s**.
- Fastest total: Q4 **9.0s**; slowest: Q9 **39.2s**.
- Compare with the Qwen3.5-4B run: 9.5/10 weighted, average TTFT 63.9s,
  average total 92.2s. Gemma is much faster but less accurate on definition and
  broad-list questions.

## Notes / limitations

- Q3 retrieval did include `Điều 3. Giải thích từ ngữ`, but Gemma ignored the
  definition and answered that no definition exists.
- Q6 retrieval returned `Chương II`, `Điều 43`, and `Điều 9` instead of
  `Điều 10`, so the model never saw the a–h list. Rephrasing the question with
  “Điều 10” triggers article-scoped retrieval and should be tested separately.
- Q5 and Q10 are broad list questions; the 4B model still compresses/duplicates
  list items even when the correct five chunks are present.
- The external server model is the main accuracy variable. If legal accuracy is
  more important than speed, use Qwen3.5-4B; if latency is more important, Gemma
  with `enable_thinking: false` is usable but should be checked on definition and
  list questions.
